# Country Flags Project

## What the project is:
This project contains flags of countries all around the world, that are build only by CSS and HTML. None of the flags are images. 
They all are coded.

## Why I Made It: (how i got this idea?)
I initially got the idea of making such project from an exercise in the course I was learning from. The original challenge of that exercise was only to build flag of laos to unerstand positioning in Css. 
But I thought "How about I create all the flags that exist in world only by CSS"🤔 and Here we are!! :D

## How To Use The Website:
This is a very simple website. It has very simple layout. You can use this website by clicking the URL in your browser or the download the code and run in the web browser (chrome, google, brave, microsoft edge etc).

Click at any countries and TADA!! you have the flag :D

## How To Run It Locally:
Don't worry! I also find it confusing how to run code from repo. But No more confusion!! 
1. Click on Code <> (green button) on the github repository
2. You will see few things after clicking on it. Click on Download ZIP
3. Let the file download
4. Extract the zipped file inside a folder.
5. Inside, find index.html
6. Click on index.html
7. If the index.html opens directly in vs code. Right click and select "show preview" (only works if you have preview extension in
   your vs code)
8. OR inside folder, right click on index.html and select OPEN WITH , choose chrome (or any brower).
9. You can view the website!!! :D
